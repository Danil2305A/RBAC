# RBAC
Интерактивная консольная утилита для управления пользователями, ролями и правами доступа с использованием модели RBAC (Role-Based Access Control)

## Инструкция по запуску утилиты
### Соберите проект
```bash
./gradlew build
```
### Запустите JAR-файл
```bash
java -jar build/libs/RBAC.jar
```
